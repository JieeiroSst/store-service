CALL CENTER AI - BẮT ĐẦU TỪ ĐÂY
================================

Tổng đài tự động: Twilio nhận cuộc gọi, Claude (dự phòng OpenAI) trả lời theo
kịch bản + kho FAQ, chuyển máy cho nhân viên khi cần, lưu mọi hội thoại vào MySQL.

TÀI LIỆU
  README.md             Tính năng, cấu hình, toàn bộ API
  QUICKSTART.md         Setup trong 10 phút
  PROJECT_STRUCTURE.md  Kiến trúc hexagonal, luồng cuộc gọi, cách thêm adapter
  DEPLOYMENT.md         Triển khai production
  INDEX.md              Mục lục tài liệu

CHẠY NHANH (Python 3.10+, khuyên dùng 3.11)
  python -m venv venv && source venv/bin/activate
  pip install -r requirements.txt
  cp .env.example .env                                   # điền key, DB, AGENT_PHONE_NUMBER...
  python -m app.adapters.inbound.cli.seed_scenarios      # tạo bảng + 6 kịch bản + FAQ mẫu
  uvicorn app.adapters.inbound.api.main:app --reload

DOCKER
  cp .env.example .env
  docker-compose up -d
  docker-compose exec api python -m app.adapters.inbound.cli.seed_scenarios

THỬ KỊCH BẢN KHÔNG CẦN GỌI ĐIỆN
  curl -X POST localhost:8000/api/simulate -H 'X-Internal-Token: <token>' \
       -H 'Content-Type: application/json' -d '{"scenario": "customer_support"}'
  curl -X POST localhost:8000/api/simulate -H 'X-Internal-Token: <token>' \
       -H 'Content-Type: application/json' -d '{"call_sid": "SIM-...", "message": "phí ship bao nhiêu"}'

KIỂM THỬ
  python -m unittest discover -s tests -t .              # unit + API, không cần DB thật
  python -m scripts.smoke_test [--with-api]              # kiểm tra DB/LLM/TTS thật

MÃ NGUỒN (app/)
  domain/        Entity, quy tắc hội thoại, tìm kiếm FAQ, kịch bản mẫu, ports
  application/   Use case: VoiceCallService, CallService, ScenarioService, KnowledgeService
  adapters/      inbound (FastAPI, Twilio, CLI) / outbound (SQLAlchemy, Claude, OpenAI, TTS)
  container.py   Nối port với adapter
  config.py      Biến môi trường

TRƯỚC KHI CHẠY THẬT
  - Sửa các FAQ mẫu theo chính sách thật (/api/knowledge): số liệu mẫu chỉ để minh hoạ
  - Đặt AGENT_PHONE_NUMBER để bot chuyển máy được, COMPANY_* để bot giới thiệu đúng
  - Đặt TWILIO_AUTH_TOKEN + PUBLIC_BASE_URL để kiểm tra chữ ký webhook
  - Đặt INTERNAL_API_TOKENS để khoá /api/*
